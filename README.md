# Maze-Creator-and-Editor
Coded using Python and Tkinter.

## Usage
You can draw and re-upload your own mazes in any size you want and ctreate new one.

### Step-1)
Enter values for the height and width. Then enter the start and end points. If you dont do that program will not work and probably crashes. **When writing the start and end points, keep in mind that the top left corner is the 0,0 point.**
### Step-2)
If you want to generate randomly, click on the "Generate" button.
If you want to design manually, click the button that says "Draw" and then if you want import your design, click the button that says "İmport" and paste the labyrinth code to commandline.
### Step-3)
Afterall when you finished your jop, click the button that says "export" and you can copy the labyrinth code from commandline.

## How Can I Use Labyrinth Code?
Every cell saves as a number between 15-0 and every number can generate with a spesific combination. You can visualize it with decoding numbers.
Left wall adds 1
Right wall adds 2
Top wall adds 4
Bottom wall adds 8
